## 维纳斯、少年、骷髅（借维纳斯的眼睛时听到）

底子：三个都只关心自己的样子。少年刚被画灯照亮，多少年来第一次看见自己；骷髅的水里映着的是少年，他低头只能看见年轻时的自己；维纳斯没有手，镜子也举不起来。

| ID | 台词 | 为什么说 |
|---|---|---|
| pov.01 | LAN：（借着她的眼睛）好高呀！ | 小孩第一次站这么高。 |
| pov.02–03 | 维纳斯：门口那个人举着的，是我的手吧？／还有一只，怎么跑到那盆树里去了。 | 她刚睁眼，第一眼就看见自己的手在别人那儿。谜题线索从她自己的着急里出来，不由旁白解释。 |
| pov.04 | 少年：灯总算亮了。等一下，我头发怎么成这样了？ | 灯刚修好，他第一件事是看自己。 |
| pov.05 | 骷髅：你还有头发呢。 | 他没有了。 |
| pov.06–07 | 少年：对面那个，你别老盯着我看。／骷髅：你以为我想看？我一低头就是你。 | 少年嫌他；骷髅也烦。之后 LAN 坐传送带经过骷髅那幅画，会亲眼看到他的水里是少年。 |
| pov.08–10 | 维纳斯：你们两个，谁帮我看看，我这半边脸是不是锈了？／少年：我只看得见我自己。／骷髅：锈了。 | 她没镜子，只能问人。少年低着头只看水；骷髅照直说。 |
| pov.11 | 维纳斯：手装回来，我自己照镜子看。 | 不信他们，要自己看。她最后的姿势是托起镜子，这里先有了来由。 |
| pov.end | LAN：我们帮她把手拿回来吧！ | LAN 听完了想帮忙。 |

改掉的：“我的左边不会老，右边一直在烂。你说，哪一边才是我？”“烂的那边。不会老的东西，不是活的。”“他以为我要指路。我只是想照一照镜子。”（下定义、讲道理、自己解说自己）。
