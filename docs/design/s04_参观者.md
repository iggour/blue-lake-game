# S04 参观者：整间展厅是一只眼睛

- 2026-11-01 初稿；**2026-11-02 与用户讨论后修订并实现**（占位图形）。本文件第 0 节是现行版本；第 1 节以后保留初稿作背景，与第 0 节冲突时以第 0 节为准。

## 0. 现行版本（2026-11-02，用户确认，已实现）

### 0.1 用户的决定
- **不用明暗对比（避免和 S03 撞车），改用色调对比：两层。**
  - 视杆层（参观者）：动态、灰调、暗。
  - 视锥层（修复师）：静态、鲜亮、彩色。
  - 两层里看得见的东西不一样，例如《双生》每层只看得见属于这一层的那一半。
- **调《窗》= 影像科医生调窗宽窗位。** 画上的窗帘就是窗。先做三个预设，正式美术时再做拖动：
  - 全开 · 亮 = 视锥窗（窄窗、高窗位）
  - 半掩 · 黄昏 = 两层各一半
  - 全合 · 暗 = 视杆窗（宽窗、低窗位）
- 粉笔描信号：方案 b（在画上用粉笔描出信号的路线，修复师照着修）。
- 参观者的三次对话对应三档光。
- “格雷汉修灯让房间裂成两层”**不用**。
- “窗是从里面关上的”这句**删掉**。
- 打开《窗》的东西两个都要：
  - 画框就是窗框：修复师卸下来修，一直没装回去。
  - 把手被涂掉了：紫外灯下显形。
- **所有痕迹统一由《戴珍珠耳机的少女》造成。** 她是会自己走出画框的画，动机就是**纯皮**（之前的雕像和画像也会说话，正好统一）。她用来画画的黄颜料就是核黄素：涂掉把手的是她，《窗》上的小手印是她的，一路的指印也是她的。之后写一两句台词暗示她认识蓝湖。
- 《双生》的双签名保留，作为紫外灯下的彩蛋。
- S07 不碰；S05 之后单独一轮改（见 0.4）。

### 0.2 实现的流程
1. 左墙进门，房间是亮的（全开）。
   - 参观者在两侧暗处，是淡淡的灰色剪影：“太亮了，看不清。你是……修灯的人吗？”
   - 修复师只看得见正前方：站在她身侧没反应，要站到她和《星空下的神经》之间才能说话。她说画的是“正在传导的信号”，可她越盯着看它越不动，修不下去。
2. E《窗》（整间屋子的光源）→ Space（S04 第一次蓝湖变形）→ 粉笔点《窗》拉窗帘：全开 → 半掩 → 全合 → 全开，循环。画上方显示当前预设和窗宽 / 窗位。
3. **余光谜题（半掩）：**
   - 参观者在黄昏里提示：“那幅《星空》在动。我总是用眼角才看得到。”
   - 正对着画看不见信号；站到侧面（修复师正前方）才看得见一条流动的信号和四个节点。
   - 用粉笔按流动方向依次点四个节点，描出路线；顺序不对会被拒绝。
   - 在半掩下描完，修复师当场照着修好（在全合下描完，要等光线回来再 E 修复师）。
4. 修复师说有人夜里在她修好的画上乱涂。那种黄颜料是核黄素，不该出现在古画里。她把一小瓶刮下来的颜料放在工作台上，请格雷汉帮她抓人。
5. **一二三木头人（少女）：**
   - 全合时，少女走出画框，成为一个灰色的小影子，在 x≈290–830 之间来回走，每次经过修复师正前方都停一下。
   - 拉回全开时，她当场定住，变成彩色。如果正好在修复师正前方（±30），就被抓住；否则定在半路，“修复师背对着她，什么也没看见”，重新拉暗她会接着走。
   - 抓住后的对话里，她朝格雷汉身边看了一眼：“你也在呀。好久不见。”这是暗示认识蓝湖的台词。她承认把手是她画掉的，然后跑回画框。修复师交出紫外灯（在工作台上）和《窗》的画框。
6. 工作台 E：先抹上核黄素，之后开 / 关紫外灯。
7. **参观者认人：** 全合、紫外灯开、身上有核黄素时，格雷汉要**走过**参观者面前（站着不动不算，“停下来就不见了”），他们才凭步态认出“那年冬天修灯的人”。之后提示：“那个小影子总在《窗》前面停一停。”
8. 《窗》：
   - 紫外灯下（半掩或全合）E，被涂掉的把手显形（黄颜料发黄绿光，下面是把手的形状）。
   - E 装回画框。
9. 认人、把手、画框三件都完成后，蓝湖说“它现在不只是一幅画了”，进入 S05。
10. 紫外灯下的其他痕迹：
    - 少女的泪痕（抓住她之后）
    - 《窗》上的小手印
    - 地上一路的指印
    - 《双生》说明牌上的两个签名（E 读）

### 0.3 实现方式
- 没有用着色器，也没有拆 CanvasGroup。`_s04_c()` 对每个颜色做窗宽 / 窗位映射：
  - 全开：提高饱和度。
  - 全合：按 窗位 0.42 / 窗宽 1.2 映射成灰蓝。
  - `s04_win_t`（0 = 全开，1 = 全合）在预设之间缓动。
- 视锥层的东西（修复师、《双生》左半）按 `_s04_cone_alpha()` 显隐；视杆层的东西（参观者、少女的影子、《双生》右半、画里的信号）按 `_s04_rod_alpha()` 显隐。另一层的人留一点淡淡的剪影，让玩家知道他们在。
- 以后做拖动时，只需把预设换成连续的窗宽 / 窗位。

### 0.5 特写（2026-11-05，用户确认，已实现）
- 9 个 E 点 → 5 个特写：修复台（修复师 + 《星空下的神经》 + 工作台，大特写）、《窗》、《戴珍珠耳机的少女》、参观者、《双生》。窗帘仍在房间里用粉笔拉（它改变的是整间屋子的光）。
- **修复台：余光谜题搬进特写。** WASD 移动的是格雷汉的视线（中央凹，半径约 58）：视线正中看到的画静止不动，信号脉冲只在视线圆圈外的余光里出现（`_s04_bench_signal_alpha()`）。看准路线后 Space 拿出 LAN 的粉笔，按顺序点四个节点（`_s04_bench_chalk()` → `_s04_trace()`，与房间里的粉笔共用）。需要先在房间里拉到半掩。
  - 修复师：视线在她脸的正前方 E 才说话；从侧面拍她没反应。
  - 工作台：E 核黄素 → 抹核黄素特写；E 紫外灯 → 开 / 关（抓到少女之后）。
- **抹核黄素（光点人）：** 视觉科学的光点步态实验（point-light walker）：只在关节上有光点，观察者也能凭运动认出是谁在走路。
  - 12 滴，WASD 移动刷子、E 抹一滴，抹满自动收起；可以回工作台“擦掉重抹”。
  - 关节 12 处：左右肩、肘、腕、髋、膝、踝（`S04_JOINTS`）。抹在关节附近（20 像素内）的点随步态摆动；别处的点在身边乱飘。
  - 紫外灯 + 全合时，格雷汉变暗，只剩光点（`_draw_point_light()`）。关节点 ≥ 8：走过参观者面前被认出；不够：“几个光点在飘……是萤火虫吗？”
- **少女的表情：** 每按一次 E 换一种，最后一次 E 收起。
  - 修好信号前：眨眼、吐舌头、摘下耳机假装听又戴回去、一碰就坐正装成普通的画。
  - 修好后：噘嘴、翻白眼、抱胸扭头。
  - 被抓后：掉眼泪（紫外灯下泪痕发光）、看见 LAN 先惊后心虚“好久不见”、比“嘘”。
  - 走出画框时：空椅子和一串黄色小脚印，E 后画外有人偷笑。
- **《窗》：** 紫外灯下显出被涂掉的把手；装回画框（E）；盲点的蓝手印，LAN 小声说“……那是我的”。
- **参观者：** 叠盘头、没有五官；三档光三种对话；被认出后头里亮起一点暖光。
- **《双生》：** 两个头背对背，各属一层；紫外灯下说明牌显出两个签名。
- **超写实插帧：** 少女第一次被定住（油画的眼睛）；第一次在紫外灯下有核黄素（皮肤上的荧光黄液体）。这两处是直接在展厅里硬切的插帧（`_hyper_flash_start()`），不在特写里。

- 讨论日期：2026-11-01，用户与 Claude。用户确认“S04 的设计都很好”。
- 当前代码里的 S04 仍是旧版（荧光剂台、感应灯 + 粉笔、灯控开关、参观者挡在《窗》前），之后按本文件重做。
- 入口：格雷汉从第二展厅里那边的门出来，从**左边**进入 S04（已实现）。

## 1. 依据（真实知识，只作主题框架，不做数值系统）

- **视杆细胞：** 每只眼睛 1 亿多个，集中在视网膜边缘，中央凹几乎没有。对弱光和运动非常敏感，只分辨明暗，看不清细节；很多视杆的信号汇到同一根神经上，灵敏但分辨率低。强光下几乎没用。
- **视锥细胞：** 几百万个，集中在中央凹，分三种（偏蓝、偏绿、偏红），负责颜色和细节，需要亮光，正对着看才最清楚。
- **余光视觉：** 看暗星时故意用眼角看，因为边缘才有视杆。
- **浦肯野效应：** 光线变暗时，红色先变黑，蓝绿色显得更亮。
- **黄昏视觉：** 不太亮也不太暗时，视杆和视锥同时工作。
- **紫外线检查：** 修复师用紫外线照画，旧清漆发荧光，后补的颜料是暗的，能看出修补和底层。紫外灯也能照出体液。
- **核黄素（维生素 B2）：** 黄色，紫外光下发黄绿色荧光。眼科有一种治疗：在角膜上滴核黄素，再用紫外线照，让角膜变结实（治圆锥角膜）。核黄素 + 紫外光 = 修补眼睛的“窗”。

## 2. 光线：拉《窗》的窗帘（不再用开关灯，避免和 S03 撞车）

- 整间展厅的光都从《窗》这幅画里照进来（和那喀索斯的真水一样，是魔幻设定）。
- 画上的窗帘可以拉，E 窗帘绳分三档：
  - **全开（亮）：** 视锥工作。修复师能干活，参观者躲在边缘、看不清。
  - **半掩（黄昏）：** 视杆和视锥都工作。《戴珍珠耳机的少女》的脸会变（见第 6 节）。
  - **全合（暗）：** 只剩视杆。参观者活跃，修复师什么也看不见。
- 窗帘调光 = 眼睛里的虹膜。窗帘也是之后的幕布，为 S08 的“窗 → 幕布 → 剧院”先露一次面。

## 3. 布局：中间亮，边缘暗

- **《窗》是瞳孔**，放在房间中央。修复师的工作台在它正下方（中央凹，光最多），旁边是《星空下的神经》。
- 参观者在左右两边的暗处。他们怕亮，不肯走进中间；修复师离开灯光就什么也看不见。
- 左边进门先遇到参观者，右边暗处有更多参观者、《戴珍珠耳机的少女》、《双生》。具体位置实现时再定。

## 4. 人物

### 参观者（视杆）
- 外形：高、瘦、圆柱形，头部像一叠硬币（视杆外段是一层层叠起来的膜盘），灰蓝单色，脸是糊的。
- 有好几个。说话时可以几个人合说一句，一人一个词，对应很多视杆汇成一根神经。
- 规则：只看得见移动的东西。格雷汉走动时他们转头；她一停下，他们就看不见她了（“刚才那个人呢？”）。认不出脸，只记得动作和步态。
- 动机：S01 冬天的照片里，格雷汉在这座美术馆修过灯。参观者在等“那个修灯的人”。
- 要去找好几次：
  1. 第一次：认错人。“是你吗？……你有没有看到一个人？戴眼镜的……”（沿用 PDF 的话。）
  2. 第二次：“是那个修灯的人吗？……看不清。太亮了。”
  3. 最后：黑暗里，抹了荧光的格雷汉在紫外灯下走过，参观者从她走路的样子认出她：“是你。那年冬天修灯的人。”接着说出通往 S05 的线索，例如“窗是从里面关上的”。

### 修复师（视锥）
- 外形：矮一些，头部或帽子是圆锥形；身上有蓝、绿、红三种颜色（三色工具或三片镜片）；戴放大镜，脸画得很清楚。
- 规则：只注意正前方的东西。格雷汉必须正正站在她面前才能和她说话，和参观者相反。
- 在修《星空下的神经》（PDF：运动模式下神经在传导信号）。画里有一层很淡、一直在流动的信号，她正对着看就看不见，所以修不下去。

## 5. 流程（“重逢”的设计已拿掉）

1. 左边进门，暗处遇到参观者：认不出格雷汉，在等“修灯的人”。
2. 中央找修复师（要正对着她）。她修不了《星空下的神经》。
3. **余光谜题：** 格雷汉站在画正前方什么也看不见，往旁边走开一些，用眼角才看得见信号流动的路线（实现：画上那一层越正对越淡，偏开一定距离最清楚）。提示可以来自参观者：“那幅画在动。我总是用眼角才看得到。”
4. 把看到的路线告诉修复师，她修完，作为谢礼给格雷汉荧光剂（核黄素），并告诉她紫外灯在哪（“我用它标记修过的地方”）。
5. 抹上荧光剂，拉合窗帘，打开紫外灯，在参观者面前走过 → 参观者凭步态认出她（第 4 节）。
6. 接 S05（打开《窗》）。

## 6. 其他展品的互动

- **《戴珍珠耳机的少女》：** 黄昏档下红嘴唇变黑、蓝耳机亮起，她的脸看上去变成另一个人，参观者会对着她说话（以为是自己要找的人）。紫外灯下可以显出泪痕（一幅讲认脸的画，因为没人认得出她而哭）。
- **《双生》：** 两人是共同创作者这条线保留，但不重逢。紫外灯下说明牌显出两个签名，一个是修复师，一个是参观者：同在一间屋子里，却再也看不见对方。只作特写细节。
- **《窗》：** 紫外灯下玻璃上显出手印，是有人从窗的**里面**按上去的，为 S05/S06 铺垫，可能和肯特阿姨有关。
- **盲点（彩蛋，代替视网膜图）：** 墙上有一块地方，大脑会用周围的墙纸自动“补”上，看不出有东西。进蓝湖才看得见，里面藏着这一章的一处蓝湖形态（形态由用户决定）。视网膜图不单独做，除非以后能推动情节。
- **蓝湖在 S04：** 按需要使用（目前只有盲点彩蛋）。
