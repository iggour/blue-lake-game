## 2. 流程骨架（Claude 草案，待用户改）

1. **开窗（S04 → S05 交界）。**
   - 把手和画框在 S04 已经齐了。《窗》画里画的正是“草地、蓝天、路、远处的红房子”。
   - Space + 粉笔点把手，画变成真的路。这是“第一次改变一样东西的本质”：S04 拉窗帘只是调整怎么看。
2. **隧道。**
   - 一条一点透视的路通向红房子，画面边缘暗下去，只剩中间。
   - 笑料：往前走，红房子一直不变大（它是注视点）。
   - 走到尽头才发现，红房子是画在远墙上的壁画（错视画 / 材质：走近了看得见笔触）。
3. **大厅。**
   - 侧墙上是视力表矩阵：远看是一张视力表，走近了每个字母（兰氏 C 环）都是一人高的展柜。
   - 清洁工在梯子上擦最上面那个字母。他给所有东西贴标签、编号（S03 门上写着格雷汉名字的资产标签是他贴的）。
   - 他的水桶翻了，水漏到楼下，也就是《那喀索斯》的真水。
4. **红房子枢纽。**
   - 透过某个 C 环的缺口（或画框、钥匙孔、《凝视》的瞳孔）注视壁画上红房子的某扇窗，就到对应的房间。
   - 那个房间找到的蓝湖痕迹，会让红房子上那扇窗亮起来（收集进度画在世界里，不做背包或列表）。
5. **肯特阿姨的视觉传感器。**
   - 藏在矩阵里清洁工从来不擦的那一格（他只擦“看得见”的东西）。
   - 显形用错觉透视：轮廓碎片分布在不同距离，只有站在某一点、透过某一个“窗”看过去才拼完整，对应“看见即存在”。
   - 原 S06 的《凝视》《盲》可以并进来，比如《盲》= 盲视：说看不见，却一直指着那一格。
