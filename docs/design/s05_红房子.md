- **玩纵深。** 这个房间里格雷汉可以往远处走，越远越小，用“近大远小”做谜题和视觉笑料。

  - 只做**几个特定物件**的透视解谜。
- **隧道视觉。** 一些神经发育多样的人有隧道视觉；这里只作为主题和视觉效果，不做数值。
- **“绿草蓝天红房子”**（验光时注视的那张图）**直接画在墙上。**
  - 透过“窗户”或任何形式的窗去注视它，就能到达对应的房间。
  - 红房子就是美术馆本身，可以借此回到任意房间找彩蛋、收集。
  - **范围只做第一章的房间。**
- **视力表矩阵 + 清洁工**，和近大远小一起做视觉幽默。
- **在最后这个房间填前面的坑：**
  - 《那喀索斯》画里的真水，是楼上清洁工的桶打翻了漏下来的。
  - S01《开幕日》照片改画成大家站在红房子前剪彩（S01 的美术改动，另做）。
- **S01 的时间交互和 Rusty Lake《四季》太像。** 可以接受，但以后少用时间类交互。
- **改名：** 英文名用 **Ultramarine**（颜色、海的意象都对；和战锤撞名无所谓）。中文名未定。暂不批量替换。

### 1.1 第二轮决定（2026-11-02 下午，用户）
- **隧道不放在开窗之后。** 放在哪里待定，见第 3 节。
- **清洁工的动机成立：**
  - 他是整理员，给所有东西编号、贴标签、排进视力表矩阵。最后一格他看不见，补不上，请格雷汉帮忙。
  - 格雷汉需要他的编号册（红房子的窗对应哪个房间）。
  - 擦窗户、擦玻璃作为谜题的一环（白内障的意象）。
- **透视谜题可以多玩。** 借鉴“垃圾堆在灯光下投出有意义的影子”的艺术（Tim Noble & Sue Webster）：清洁工扫起来的东西，从某个角度、在某盏灯下，投在墙上会拼成一个暗示。
- **标准距离线不要。** 改成：用展台上的老镜片调焦，才能看清 C 环。
- **近处挡住远处要用，但要更有趣。** 可以借鉴病理性的“分不清大小”的体验（待设计，见第 3 节）。
- **枢纽操作定了：** 站在某个“窗”前（C 环缺口、画框、样品的瞳孔），和墙上红房子对齐时按 E 注视。不新增按键。
- **传感器为什么在这里：** 这个展厅展览的是**视觉传感器的迭代**，有一系列版本和视觉体验的样本。肯特阿姨的是其中一件，也是独特、不可复制的一件。
  - 背景：肯特阿姨是**蜘蛛型战斗机器人，有好几对眼睛**。具体能力结合节肢动物的视觉来设计，可以作为解谜的一环。
  - 清洁工负责整理、定期擦洗这些容易蒙尘的组件。
- **《盲》《凝视》不再是雕塑展品**，改成系列样品之一，或者测试处。
- **出口和之前一样：** 格雷汉犹豫后偷走阿姨的组件，保安追，翻窗逃走，窗帘变幕布，落到剧院舞台。（原来的“拿走 / 留下”二选一取消？待确认。）

## 2. 流程骨架（Claude 草案，待用户改）

### 2.1 现行结构（2026-11-02 晚，用户确认）
- 单线，只能偷。红房子回访是可选收集。
- **S05（已实现第一版）**：开窗 → 迭代展（纵深）→ 清洁工远远把格雷汉当展品贴标签 → 走近认出“修灯的” → 老镜片：推到最里面清洁工才看得见、替她擦干净（白内障 / 近大远小）→ 拉回焦点 → 目镜里看见最后一格有八个小镜头。
- **S06（下一轮）**：清洁工扫起来的垃圾在灯下投出肯特阿姨（多眼蜘蛛）的剪影，剪影的眼睛指向那一格；擦开那一格；靠阿姨的眼睛（跳蛛：用模糊判断距离）让传感器显形。
- **S07**：红房子枢纽，透过 C 环缺口 / 画框 / 样品的瞳孔注视壁画上的窗，E 回到第一章的房间找彩蛋，找到的房间对应的窗亮起来。
- **S08**：犹豫后偷走传感器 → 保安追 → 逃跑路线收窄成隧道（紧张时的隧道视野）→ 翻窗 → 窗帘变幕布 → 剧院舞台。

### 2.2 S05 实现细节（占位数值，试玩后调）
- 纵深：远墙 z = 1，近处 z = 0；远处缩到 0.5 倍；W/S 走纵深。只在这个展厅开启，离开时还原。
- 导轨 6 格（z 0.12 起，每格 0.15），对焦在第 2 格；推到第 5 格时清洁工擦镜片（要先和他说过话）。

- 最后一行 C 环缺口：下、上、右、左，第五格是八个小镜头（还没用到，S06 可以接）。
