# S04–S08 台词动机表（2026-11-10，按 `docs/台词工作流.md`）

这一轮改了 102 处。下面只列改动大的和新写的；其余是去掉“你”（对玩家说话）、“好像”、成串省略号，以及把旁白换成人物自己的话。

## 人物底子

- **修复师**：手艺人，只看得见正前方，埋头干活，话短，烦有人动她修好的画。和 S01 照片里那句“啧，刚画上去的”是同一个人。
- **少女**：会从画框里跑出来的画，纯皮。认识 LAN，不点破。
- **参观者**：缩在暗处，只看得见动的东西，说话犹豫，一句一句往外挤。
- **清洁工**：给什么都编号，自言自语。看东西忽大忽小。
